## მასალის დამატება

ყველაფერი **`data.js`**-შია — სხვა ფაილს ხელი არ სჭირდება.

```js
{
  id: "modals",                  // ლათინური, უნიკალური — არ შეცვალო
  name: "მოდალური ზმნები",       // აპში ჩანს
  cards: [
    { en: "to be fed up with", ka: "ყელში ამოსვლა",
      ex: "I'm fed up with it.", exka: "ყელში ამომივიდა." }
  ]
}
```

⚠️ **წესები:**
- ახალი ბარათი ჯგუფის **ბოლოში** დაემატოს.
- ძველი ბარათის `en` ტექსტი არ შეიცვალოს — პროგრესი („ვიცი“) მასზეა მიბმული.
- ჯგუფის `id` არ შეიცვალოს.
- `ex` / `exka` არასავალდებულოა.

ცვლილების შემდეგ: `git add -A && git commit && git push` — GitHub Pages თავისით განახლდება.
`sw.js`-ში `V` ვერსია გაზარდე მხოლოდ მაშინ, როცა **ფაილების სია** იცვლება.
