**დონეებად დაყოფა არ არის.**

## ჯგუფს ანიჭებს ხატია, თვითონ, ტელეფონიდან

Claude ახალ მასალას **📥 გასანაწილებელში** ამატებს — ჯგუფის გარეშე. შემდეგ აპში:

1. 📥 გასანაწილებელი → თემის არჩევა (ან „📦 ყველა ერთად")
2. ✔️ ყველას მონიშვნა, ან ბარათების ცალ-ცალკე მონიშვნა
3. 🗂 ჯგუფის მინიჭება → განყოფილება + ჯგუფი → ✅

**ჯგუფის შეცვლა მოგვიანებით:** ჯგუფში შესვლა → „🗂 ბარათების სია / ჯგუფის შეცვლა",
ან პირდაპირ ბარათზე — „🗂 ჯგუფის შეცვლა". ასევე: „📥 გასანაწილებელში დაბრუნება".
ახალი ჯგუფი ⚙️ ჯგუფები-დან ან მინიჭების ეკრანიდან („➕ ახალი ჯგუფი").

⚠️ მინიჭება **ტელეფონის ბრაუზერში** ინახება. ⚙️ ჯგუფები-ში არის „📤 ჩემი დალაგების ასლი" —
ის ტექსტი ჩატში ჩააგდე და დალაგება `data.js`-შიც ჩაიწერება (სხვა ტელეფონზეც გადმოვა).

## რა აქვს

- 📇 **ბარათები** — წინა მხარეს პასუხი არ ჩანს, დაჭერით ბრუნდება
- ✍️ **ტესტი** — 4 ვარიანტი; არასწორ პასუხზე წერს, არჩეული ქართული **რომელ** ინგლისურს ეკუთვნის
- 🔄 **ორი მიმართულება** — EN → ქარ და ქარ → EN
- 🏆 **„ვიცი“ ორივე მიმართულებით ცალკე ითვლება** (ერთი მხარე = ½)
- 🔊 ხმა ამერიკული აქცენტით · 📊 პროგრესი · 📴 ოფლაინ (PWA)

## მასალის დამატება (Claude-ისთვის)

მასალა **`scripts/build_data.py`-ის `SOURCE`-შია**, ისე, როგორც ხატიამ მოგვცა:

```
1. თემის სათაური
1. English idiom. — ქართული მნიშვნელობა.
```

ახალი პორცია **ბოლოში** დაემატოს, მერე:

```
python scripts/build_data.py     # აწყობს data.js-ს (300 ბარათი, 30 თემა)
node scripts/test.js             # ამოწმებს აპს
git add -A && git commit && git push
```

⚠️ **წესები:**
- `data.js`-ს ხელით არ ვარედაქტირებთ — გენერირდება.
- ძველი ბარათის `en` ტექსტი არ შეიცვალოს: პროგრესიც და ხატიას მინიჭებული ჯგუფიც მასზეა მიბმული.
- თემის სათაურში ტირე (—) არ იყოს — პარსერი მას ბარათად წაიკითხავს. (გამოიყენე „(II)".)
- ქართული ბრჭყალი: დამხურავი **“** (U+201C), არა `"` — თორემ JS-ის სტრიქონი ტყდება.
- ბარათები მხოლოდ `sec:null, grp:null`-ით ემატება — ჯგუფს ხატია ანიჭებს.
